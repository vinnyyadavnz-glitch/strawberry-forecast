Export destination (overwrite the same shared file)

In Chrome or Edge, Export can write straight into one chosen file every time — no Downloads folder, no dated copies, just overwrite in place. Point it at the master .xlsx inside your synced OneDrive/SharePoint folder once, and every future Export updates that exact file. (This uses your browser's File System Access feature — Safari and Firefox don't support it yet, so on those, Export instead downloads a fixed-name file you move into the shared folder by hand.)

Getting the latest data (recommended: OneDrive sync)

This app has no live connection to SharePoint — a browser can't silently pull a file from your organisation's SharePoint without you being logged in, and SharePoint blocks that kind of automatic fetch for security reasons. The reliable way to always have the current file on hand is to let OneDrive keep a synced copy on your device, then Import from that synced folder like a normal local file.

One-time setup on each PC (senior grower, farm manager, GM):
1. Open the KBL 2026-2027 SharePoint site → Documents → find the master file's folder.
2. Click Sync in the toolbar (or open the same library through the OneDrive app already installed with Microsoft 365).
3. That folder now appears in File Explorer like any other folder, and updates itself in the background every time the junior grower re-exports and saves a new version back to SharePoint.
4. Each week: open this app → Import (below) → browse to that synced OneDrive folder → pick the file. It's always current, no link-pasting, no login prompts.

On the junior grower's tablet (entering the actual data): if it's an iPad/Android tablet, use the OneDrive app to open or save a local copy of the file before importing, then use Export here and upload the result back into the same OneDrive/SharePoint folder when done.
Advanced / optional: auto-fetch from a direct link
This only works for a personal OneDrive file or a link shared as "Anyone with the link" with anonymous access allowed — it will not work for a normal organisational SharePoint link like the ones in your KBL library, since those require you to be logged in and SharePoint won't allow a browser script to read the file across sites. Leave this blank and use OneDrive sync + Import above instead unless you specifically have a public/anonymous link.

Bulk data import (CSV / XLSX)

Upload a .csv or .xlsx file instead of typing data in one row at a time. An .xlsx workbook can carry all five data types at once on separate sheets named Blocks, Plantings, FlowerScans, Environment and Harvest. A .csv file can only hold one sheet, so upload one file per data type — the format is auto-detected from the column headers. New blocks referenced in an upload (e.g. D, E) are created automatically. Plantings rows (Block, Tunnel, Row, Name, Bags, No. Of Holes Per Bag, No. Of Plants, Planting Date) feed the new Planting tab and roll up into each block's total bags and plants automatically.
